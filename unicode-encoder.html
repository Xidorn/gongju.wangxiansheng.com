工具介绍

Unicode 编码工具适合将普通文本转换成 Unicode 转义格式，或把 Unicode 转义内容还原成原始文本。 常见于前端开发、脚本配置、接口传输、字符调试和多语言文本处理场景。

使用方法

  1. 在左侧输入框中输入文本或 Unicode 转义内容。
  2. 选择“Unicode 编码”或“Unicode 解码”模式。
  3. 编码模式下可选择输出为 \uXXXX 或 HTML 实体格式。
  4. 系统会自动实时转换，也可以点击“立即转换”手动执行。
  5. 点击“交换内容并切换模式”后，可快速反向处理。

常见问题

\uXXXX 和 HTML 实体有什么区别？
\uXXXX 常见于 JavaScript、JSON 等场景；HTML 实体如 &#x4F60; 更常见于 HTML 页面或富文本环境。
为什么有些 Emoji 不是一个 \uXXXX？
因为部分字符超出了基本多文种平面，会使用代理对形式表示，例如 😀 可能会编码成两个 Unicode 转义片段。
解码失败怎么办？
如果输入内容格式不完整，或者包含非法的转义片段，解码时可能失败。可以先检查 \u 或 HTML 实体是否写完整。
