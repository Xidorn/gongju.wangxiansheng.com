使用方法

  1. 选择“HTML 实体转义”或“HTML 实体反转义”模式。
  2. 在左侧输入框中输入或粘贴内容。
  3. 系统会自动实时转换，也可点击“立即转换”手动执行。
  4. 可通过“交换内容”快速进行反向处理。

常见问题

什么时候需要 HTML 转义？

当你想在网页里展示代码片段，而不是让浏览器直接渲染标签时，就需要先做 HTML 转义。

反转义后能直接渲染吗？

可以还原为原始字符内容，但是否渲染还取决于你后续把结果放在页面的哪个位置以及采用什么插入方式。
