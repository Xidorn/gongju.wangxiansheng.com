工具介绍

这个在线代码美化工具基于 Prettier 实现，适合快速整理 HTML、CSS 和 JavaScript 代码格式。 不管是复制粘贴后的混乱代码，还是需要统一团队编码风格的代码片段，都可以在这里快速完成格式化。

使用方法

  1. 在左侧输入框中粘贴代码内容。
  2. 可选择“自动识别语言”，也可以手动指定 HTML、CSS 或 JavaScript。
  3. 根据需要选择 2 空格或 4 空格缩进。
  4. 开启“实时美化”后会自动格式化，也可以点击“立即美化”手动执行。
  5. 格式化完成后可复制结果或下载为文件。

常见问题

支持哪些代码类型？
当前支持 HTML、CSS 和 JavaScript 三类常见前端代码格式化。
自动识别语言是怎么工作的？
页面会根据代码内容的特征判断更像 HTML、CSS 还是 JavaScript。 如果识别结果不符合预期，也可以手动切换语言后重新美化。
为什么有时会提示格式化失败？
一般是因为代码本身存在语法错误或不完整，例如缺少括号、引号或结束标签。 这时你可以先检查原始代码，再重新执行美化。
