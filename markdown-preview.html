工具介绍

Markdown 实时预览 / 转 HTML 工具适合写说明文档、项目 README、博客草稿、产品介绍等内容场景。可在左侧输入 Markdown，并在右侧实时查看预览或切换查看 HTML 源码。

使用方法

  1. 在左侧输入框中粘贴或输入 Markdown 内容。
  2. 系统会自动实时渲染，也可以点击“立即渲染”手动执行。
  3. 点击“HTML 源码”可查看转换后的结构化代码。
  4. 确认无误后可一键复制 HTML 结果。
