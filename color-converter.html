工具介绍

颜色转换器适合前端开发、设计协作、配色整理和样式调试等场景。支持 HEX、RGB、RGBA、HSL、HSLA 常见格式互相转换，并可实时预览颜色效果。

使用方法

  1. 在输入框中输入 HEX、RGB 或 HSL 颜色值。
  2. 系统会自动识别并完成转换，也可以点击“立即转换”。
  3. 右侧会显示颜色预览，以及对应的 HEX / RGB / HSL 结果。
  4. 可单独复制某种格式，或一键复制全部结果。

常见问题

支持透明度吗？

支持。输入 RGBA 或 HSLA 时会保留透明度信息并展示预览效果。

为什么有时输入后识别失败？

通常是因为格式不完整，例如漏写括号、逗号或百分号。建议按标准格式输入。
